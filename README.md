Campus Nexus

Campus Nexus is a comprehensive, web-based platform designed to bridge the gap between students, campus activities, and essential university resources. Featuring a sleek, modern, and highly responsive user interface, it centralizes event discovery, academic resources, and community engagement into a single, intuitive dashboard. 

Built with scalability and user experience in mind, Campus Nexus utilizes a robust Node.js and MongoDB backend to ensure seamless performance, while delivering a premium, aesthetically driven frontend experience for students and faculty alike.

Key Features
- *Centralized Hub:** Discover college activities, events, and vital resources seamlessly.
- *Premium UI/UX:* Built with a clean, dynamic, and accessible design system.
- *Robust Architecture:* Powered by an Express.js backend and MongoDB Atlas for reliable performance.
- *Cloud Hosted:* Seamlessly deployed and globally served via Vercel.
